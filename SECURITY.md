# Security Policy

## Scope

This repository is a public documentation project and portfolio artifact.

It does not host production systems, credentials, or customer data.

## Reporting a Vulnerability

If you believe you have identified a security issue in this repository or its supporting automation:

1. Do not open a public issue with exploit details.
2. Contact the maintainer privately using the contact details available on the maintainer's GitHub profile, and include a clear description of the concern, affected files, and reproduction steps if relevant.
3. Allow reasonable time to review and respond before sharing details publicly.

## What to Report

- exposed secrets or credentials
- unsafe automation behavior
- malicious dependency or workflow concerns
- content that could create misleading or unsafe security guidance

## Response Goals

The maintainer will review reports in good faith and aim to acknowledge valid submissions promptly.

Because this is a public educational repository, fixes may focus on removing risk, correcting guidance, or disabling unsafe automation rather than preserving backward compatibility.
