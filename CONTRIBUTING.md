# Contributing

Thanks for your interest in improving this repository.

## What This Repository Optimizes For

- clear, practical security communication
- business-aligned security reasoning
- generalized examples that are safe for public sharing
- concise documents that are easy to skim

## Contribution Guidelines

- keep content professional, practical, and vendor-neutral unless a vendor example is necessary
- avoid employer-specific, confidential, or environment-specific references
- prefer short sections, short paragraphs, and direct language
- preserve lowercase, hyphenated file naming where possible
- use relative Markdown links between documents

## Pull Request Expectations

- explain what changed and why it improves the repository
- keep scope focused
- avoid adding filler content or speculative claims
- update cross-links when adding new documents

## Before You Submit

- confirm the change is public-safe
- confirm there are no internal workflow artifacts such as `.codex` or `AGENTS.md`
- confirm the content does not suggest it was AI-generated
- review formatting and link correctness
